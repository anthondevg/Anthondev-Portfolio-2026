# Anthony Gonzalez — AI Engineer Portfolio

Editorial portfolio built with Next.js, TypeScript, Tailwind CSS, Motion, React
Three Fiber, and local MDX case studies.

## Local development

```bash
npm install
npm run dev
```

Use `npm run lint` and `npm run build` before publishing.

## Content

Case studies live in `src/content/work`. Replace the clearly marked draft
content with verified project information and outcomes.

Before the final public launch, replace:

- Portrait placeholder
- Email, LinkedIn, and GitHub links
- Résumé placeholder
- Employment history
- Three draft case studies

Set `NEXT_PUBLIC_SITE_URL` to the final custom domain when one is connected.
